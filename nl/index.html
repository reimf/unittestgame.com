UnitTestGame koppelt je aan een tegenstribbelende AI bot. Hij schrijft correcte code die voldoet aan je unit testen. En niets meer. Jouw taak: schrijf unit testen totdat het programma klopt.

Speel gratis in je browser → Bekijk hoe het werkt

Ik wil deze unit test toevoegen.

isAllowedToVote(18) === true
dit ben jij ↑ met je eerste unit test
function isAllowedToVote(age) {
return true
}
↑ dit is de AI bot zijn eerste functie voldoet aan je unit test maar het generaliseert niet 👎

Ik wil deze unit test toevoegen.

isAllowedToVote(17) === false
dit ben jij weer ↑ nu met je tweede unit test
function isAllowedToVote(age) {
if (age >= 18) return true
return false
}
↑ dit is de AI bot weer zijn tweede functie voldoet aan beide unit testen en nu generaliseert het wel 👍

Leer unit testen schrijven op gevoel

Geen video's. Geen quizjes. Gewoon een AI bot die elk gat in je unit testen uitbuit.

  1. ① Lees de spec

    Bekijk wat de functie moet doen, in simpele input → output termen.

  2. ② Zie hem vals spelen

    De AI bot schrijft correcte code die precies voldoet aan wat jij hebt getest.

  3. ③ Vind het gat

    Spot het randgeval dat hij ontweek, en voeg een unit test toe die dat blootlegt.

  4. ④ Ga door tot het klopt

    Herhaal tot er geen andere weg meer is. Level voltooid!

Voor developers die bugs willen voorkomen

Het speelt als een spel. Het wordt een gewoonte. Het verandert hoe jij test.

  • 🕵️ Een waardige tegenstander

    De AI bot stribbelt tegen. Elke zet is een les over jouw blinde vlek.

  • 📈 Oplopende moeilijkheidsgraad

    Begin met batterijniveaus. Eindig met het ontrafelen van snelheidsdisplays en parkeerkosten.

  • 🔓 Echte progressie

    Een scorebord houdt bij wat je hebt ontgrendeld, zodat je altijd weet wat je te wachten staat.

  • 🌍 Zes talen

    In het Nederlands natuurlijk, maar ook in het Engels, Duits, Frans, Spaans of Italiaans.

  • 💻 Zeven programmeertalen

    Laat de AI bot programma's schrijven in JavaScript, TypeScript, Python, Java, C#, PHP of Ruby.

  • 🧩 Helemaal geen installatie

    Draait volledig in de browser. Geen account, geen installatie, geen afhankelijkheden.
