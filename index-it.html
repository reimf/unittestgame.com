UnitTestGame ti abbina a un bot IA sfuggente. Scrive codice corretto che soddisfa i tuoi unit test. E niente di più. Il tuo compito: scrivere unit test finché il programma non è corretto.

Gioca gratis nel tuo browser → Scopri come funziona

Voglio aggiungere questo unit test.

isAllowedToVote(18) === true
questo sei tu ↑ con il tuo primo unit test
function isAllowedToVote(age) {
return true
}
↑ questo è il bot IA la sua prima funzione supera il tuo unit test ma non generalizza 👎

Voglio aggiungere questo unit test.

isAllowedToVote(17) === false
questo sei di nuovo tu ↑ ora con il tuo secondo unit test
function isAllowedToVote(age) {
if (age >= 18) return true
return false
}
↑ questo è di nuovo il bot IA la sua seconda funzione supera entrambi i unit test e ora generalizza 👍

Impara i unit test con la pratica

Niente video. Niente quiz. Solo un bot IA che sfrutta ogni falla nei tuoi unit test.

  1. ① Leggi la spec

    Scopri cosa dovrebbe fare la funzione, in semplici termini di input → output.

  2. ② Guardalo barare

    Il bot IA scrive codice corretto che soddisfa esattamente quello che hai testato.

  3. ③ Trova la falla

    Individua il caso limite che ha evitato, e aggiungi un unit test che lo smascheri.

  4. ④ Continua finché non è corretto

    Ripeti finché non c'è più un altro modo. Livello completato!
