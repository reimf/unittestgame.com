UnitTestGame stellt dir einen ausweichenden KI-Bot zur Seite. Er schreibt korrekten Code, der deine Unit-Tests besteht. Und nichts weiter. Deine Aufgabe: Schreibe Unit-Tests, bis das Programm stimmt.

Kostenlos im Browser spielen → Sieh, wie es funktioniert

Ich möchte diesen Unit-Test hinzufügen.

isAllowedToVote(18) === true
das bist du ↑ mit deinem ersten Unit-Test
function isAllowedToVote(age) {
return true
}
↑ das ist der KI-Bot seine erste Funktion besteht deinen Unit-Test aber sie verallgemeinert nicht 👎

Ich möchte diesen Unit-Test hinzufügen.

isAllowedToVote(17) === false
das bist du wieder ↑ jetzt mit deinem zweiten Unit-Test
function isAllowedToVote(age) {
if (age >= 18) return true
return false
}
↑ das ist der KI-Bot wieder seine zweite Funktion besteht beide Unit-Tests und jetzt verallgemeinert sie 👍

Lerne Unit-Tests aus dem Gefühl heraus zu schreiben

Keine Videos. Keine Quizze. Nur ein KI-Bot, der jede Lücke in deinen Unit-Tests ausnutzt.

  1. ① Lies die Spec

    Sieh dir an, was die Funktion tun soll, in einfachen Input-→-Output-Begriffen.

  2. ② Sieh ihm beim Schummeln zu

    Der KI-Bot schreibt korrekten Code, der genau das erfüllt, was du getestet hast.

  3. ③ Finde die Lücke

    Erkenne den Grenzfall, dem er ausgewichen ist, und füge einen Unit-Test hinzu, der ihn aufdeckt.

  4. ④ Mach weiter, bis es stimmt

    Wiederhole, bis es keinen anderen Weg mehr gibt. Level geschafft!

Für Entwickler, die Bugs vermeiden wollen

Es spielt sich wie ein Spiel. Es wird zur Gewohnheit. Es verändert deine Art zu testen.

  • 🕵️ Ein würdiger Gegner

    Der KI-Bot weicht aus. Jeder Zug ist eine Lektion über deinen blinden Fleck.

  • 📈 Steigender Schwierigkeitsgrad

    Beginne mit Batteriestufen. Ende beim Entwirren von Geschwindigkeitsanzeigen und Parkgebühren.

  • 🔓 Echter Fortschritt

    Ein Scoreboard zeigt, was du freigeschaltet hast, sodass du immer weißt, was als Nächstes kommt.

  • 🌍 Sechs Sprachen

    Auf Deutsch natürlich, aber auch auf Englisch, Niederländisch, Französisch, Spanisch oder Italienisch.

  • 💻 Sieben Programmiersprachen

    Lass den KI-Bot Programme schreiben in JavaScript, TypeScript, Python, Java, C#, PHP oder Ruby.

  • 🧩 Gar keine Einrichtung

    Läuft komplett im Browser. Kein Konto, keine Installation, keine Abhängigkeiten.

Zehn Levels, zehn Arten, ausgetrickst zu werden

Jedes wirkt einfach. Bis der KI-Bot etwas findet, das du zu testen vergessen hast.

  1. 0 leicht

    Battery Level

    Der KI-Bot macht es dir zuerst vor. Dann bist du dran.

  2. 1 leicht

    Voting Age

    Darfst du wählen? Zwei mögliche Ergebnisse.

  3. 2 leicht

    Wind Scale

    Drei Schwellenwerte zwischen Flaute und Sturm.

  4. 3 mittel

    Review

    Preis und Qualität, gegeneinander.

  5. 4 mittel

    Discount

    Ein voller Warenkorb, eine Mitgliedskarte, oder beides zugleich.

  6. 5 mittel

    FizzBuzz

    Jeder kennt FizzBuzz. Der Bot nicht.

  7. 6 mittel

    Leap Year

    Eine Ausnahme von der Ausnahme von der Regel.

  8. 7 schwer

    Triangle Type

    Jede Seite verändert das Urteil.

  9. 8 schwer

    Speed Display

    Die physische Anzeige hat Grenzen. Finde sie alle.

  10. 9 schwer

    Parking Fee

    Kostenlos, pauschal, oder pro Minute. Was jetzt?

Häufig gestellte Fragen

Keine Verkaufsmasche. Nur Antworten.

  • Q Ist es wirklich kostenlos?

    Ja. Keine Werbung, kein Tracking, keine Bezahlschranke. Einfach ein kostenloses Spiel.

  • Q Welche Programmiersprachen werden unterstützt?

    Lass den KI-Bot Programme schreiben in JavaScript, TypeScript, Python, Java, C#, PHP oder Ruby.

    Nein. Es läuft komplett in deinem Browser. Ohne externe Bibliotheken.

    Nein. Du kannst nur anonym spielen.

  • Q Welche Informationen werden gespeichert?

    Dein Fortschritt wird in deinem Browser gespeichert. Er verlässt nie deinen Computer.

    Ja. Der Quellcode ist auf GitHub verfügbar.

  • Q Wer hat das gemacht?
